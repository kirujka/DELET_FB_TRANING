# Начало ФБ (FB Anfang) — v0.1

Мини-приложение к Forumsbeitrag v0.2: только начало текста — от первого предложения (перефразирование темы) до первого довода и слов темы. К каждой немецкой строке — русский перевод.

## Вкладки

| Вкладка | Что там |
|---|---|
| Как строить | 7 шагов: голова → слово после in Sachen → предложение 1 → предложение 2 → позиция → довод 1 → слова темы. В конце весь путь на трёх темах (№9, №1, №16). |
| Шпаргалка | Все головы, хвосты второго предложения, доводы, рамки со словами темы, «предложения потери», точные слова для 15 тем — на одном экране. |
| Тренажёр | Случайная тема: сам выбираешь голову, слово, хвост, довод → приложение проверяет и объясняет. В конце — всё начало целиком. |
| 30 начал | Готовые начала (блоки 1–5b) для 30 тем, можно закрыть русский или немецкий для заучивания. |

Метки: **СОВЕТ** — ещё не решено (ждёт корректора) · **ДА** — ты согласен · **ТВОЁ** — из твоего шаблона · **ВЫБОР** — варианты на выбор.

## Как выложить

Новый репозиторий (например `TEST-fb-anfang`), загрузить все файлы из архива, включить GitHub Pages (Settings → Pages → main / root).
Данные собираются скриптом `build_einstieg.py` из генератора ФБ v0.2 (в проекте Claude: `claude/fb-anfang/`, `claude/FB_v02_build.py`).
